# Geneteka Search Workflow

A step-by-step guide to searching Geneteka (geneteka.genealodzy.pl) effectively.

## What is Geneteka?

Geneteka is the largest free index of Polish vital records (births, marriages, deaths). It contains over 65 million indexed records from parishes across Poland, Ukraine, Belarus, and Lithuania.

**Important**: Geneteka is an INDEX, not the original records. It tells you WHERE to find records. Always verify against original images when possible.

## Before You Start

Gather this information:
- Surname(s) you're searching for
- Approximate time period (years)
- Geographic area (voivodeship, town, or parish if known)
- Spouse's surname (for marriage searches)

## Step 1: Access Geneteka

1. Go to: https://geneteka.genealodzy.pl/
2. The interface is primarily in Polish but navigable

## Step 2: Choose Search Scope

### Option A: Search All Voivodeships
Use when you don't know where the family lived.

1. Select "Wszystkie" (All) or leave the region selector empty
2. This searches ALL indexed records

### Option B: Search Specific Voivodeship
Use when you know the general region.

1. Click on the voivodeship name from the list on the main page
2. Coverage statistics are shown for each voivodeship

**Coverage varies greatly:**
- Best: mazowieckie (12M), łódzkie (9.7M), małopolskie (6.7M)
- Limited: dolnośląskie (52K), lubuskie (10K)

## Step 3: Enter Search Criteria

### Basic Search Fields

| Field | Polish | How to Use |
|-------|--------|------------|
| Surname | Nazwisko | Primary surname to search |
| Surname 2 | Nazwisko 2 | Spouse's surname (for marriages) |
| Year from | Rok od | Start of date range |
| Year to | Rok do | End of date range |
| Parish | Parafia | Specific parish (optional) |

### Record Type Selection

- **B** (urodzenia) = Births
- **S** (śluby) / M (małżeństwa) = Marriages
- **D** (zgony) = Deaths

Select which record types to search.

## Step 4: Execute Search

1. Click "Szukaj" (Search)
2. Results appear in a table

### Understanding Results

| Column | Meaning |
|--------|---------|
| Rok | Year |
| Parafia | Parish name |
| Akt | Act number |
| Imię | First name |
| Nazwisko | Surname |
| Uwagi | Remarks (parents, spouse, etc.) |

## Step 5: Refine Common Surname Searches

For common surnames (Kowalski, Nowak, Wiśniewski, etc.):

1. **Use Surname 2**: Enter spouse's maiden name
2. **Narrow by parish**: If you know the parish
3. **Use remarks**: Look at "Uwagi" for parent names
4. **Cross-reference**: Find a marriage, then search for birth using parents' names

### Example: Finding Jan Kowalski

1. Search: "Kowalski" + "Nowak" (wife's maiden name) in marriages
2. Find marriage record showing parents' names
3. Search for Jan's birth using father's name from marriage record
4. Search for siblings using parents' names

## Step 6: Handle Name Variants

Geneteka has some fuzzy matching, but try:

| Variant Type | Example | Try Both |
|--------------|---------|----------|
| rz/ż | Rzeszowski | Żeszowski |
| ó/u | Góra | Gura |
| ending variations | Kowalski | Kowalsky, Kowaliski |
| with/without przydomek | Kowalski Prusak | just Kowalski |

## Step 7: Interpret the Remarks (Uwagi)

The "Uwagi" column often contains valuable information:

### Birth Records
- "s. Jana i Marianny z Nowaków" = son of Jan and Marianna née Nowak

### Marriage Records
- "c. Wojciecha i Katarzyny z Wiśniewskich" = daughter of Wojciech and Katarzyna née Wiśniewska
- Parents of BOTH spouses often listed

### Death Records
- Age at death
- Spouse's name for married people
- Parents' names for children

## Step 8: Find the Original Record

Once you have the index entry:

1. Note: Parish name, Year, Act number
2. Go to Szukaj w Archiwach (szukajwarchiwach.gov.pl)
3. Search for the parish
4. Navigate to the correct year and act number
5. View the original scanned image

See `workflows/szukaj-w-archiwach.md` for detailed navigation.

## Step 9: Record Your Search

In your Research Log, note:
- Date of search
- Surname(s) searched
- Voivodeships/parishes checked
- Results found (with full citations)
- Parishes with NO coverage (to avoid re-searching)

## Tips and Tricks

### Finding Parents
1. Find a marriage record (best source for parents' names)
2. Use parents' names from marriage to search for birth record
3. Search for siblings (may find more records)

### Finding Siblings
1. Search by father's first name + mother's maiden name in birth record remarks
2. In marriages, siblings may list same parents

### Checking Coverage
- Click on a voivodeship to see which parishes are indexed
- Click on a parish to see which years are indexed
- If a parish isn't listed, it's NOT in Geneteka

### Dealing with Gaps
Not finding records? Possible reasons:
1. Parish not indexed in Geneteka
2. Records don't survive
3. Name spelling differs from your search
4. Wrong voivodeship (family moved)

## Common Mistakes to Avoid

1. **Only searching one spelling**: Try all variants
2. **Ignoring Surname 2**: For marriages, use spouse's name
3. **Assuming complete coverage**: Many parishes are NOT indexed
4. **Not checking remarks**: Uwagi contains critical information
5. **Trusting index blindly**: Always verify against original image
